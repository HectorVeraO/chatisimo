## 2. What Chatisimo Provides

Chatisimo provides two slash-command features inside Discord servers and direct messages with the Bot:

- **Gift Exchanges (`/ge`, `/chatisimo`)**: creating and joining group gift exchanges, configuring draw rules and mutual or one-way exclusions, storing participant gift preferences, running secret draws and scheduled reveals, and relaying anonymous questions and answers between a giver and their assigned recipient.
- **UC Match Calendar (`/uc`, `/chatisimo uc`, `/uc-config`)**: checking public Universidad Católica match fixtures and blocked availability windows, and delivering optional Friday and matchday alerts to a server channel configured by a server manager.

- Server administrators may remove Chatisimo from their server or clear UC alert settings (`/uc-config clear`) at any time.

## 5. AI-Assisted Text

When configured by the operator, Chatisimo uses a large language model (Google Gemini on Vertex AI) to:

1. Rephrase anonymous gift-exchange questions and answers so writing style does not reveal the sender's identity before reveal day.
2. Generate short group-chat banter lines from public match-schedule metadata on `/uc` replies and match alerts.

AI-generated phrasing and public sports-schedule data (sourced from ESPN) may occasionally contain inaccuracies or delays. Match kickoff times and gift-exchange details are provided for informal social coordination only.
